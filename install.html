Reinata-05

Jadwal main & keuangan band

Android

Unduh APK
  1. Ketuk Unduh APK di atas. Jika Chrome bertanya, pilih Tetap unduh.
  2. Buka file Reinata-05.apk dari notifikasi unduhan atau folder Download.
  3. Jika muncul peringatan, ketuk Setelan lalu aktifkan Izinkan dari sumber ini, kemudian kembali.
  4. Ketuk Instal. Jika Play Protect bertanya, pilih Tetap instal.
  5. Buka aplikasi lewat ikon emas R05 di layar HP.

iPhone

  1. Buka halaman ini di Safari (bukan Chrome).
  2. Ketuk Buka Aplikasi di bawah.
  3. Ketuk tombol Bagikan (kotak dengan panah ke atas) di bawah layar.
  4. Pilih Tambah ke Layar Utama, lalu ketuk Tambah.
Buka Aplikasi
Data tersimpan di HP masing-masing. Gunakan Ekspor data di dalam aplikasi untuk menyimpan cadangan, dan Impor data untuk memulihkannya di HP baru.
